Documentation Center

Central hub for admin documentation pages, routes, and setup notes.

1. Overview

The admin documentation center is the landing page for the built-in guides that explain how each admin module works. It is designed to help developers, support staff, and buyers understand routes, workflows, UI sections, file locations, and related docs.

Primary entry points

  • /admin/docs — documentation center index
  • /admin/docs/{page} — individual documentation page

Core idea

  • One doc page per admin route/module
  • Docs are generated from config metadata
  • Each page highlights access, workflow, endpoints, files, and related docs

2. Routes and Files

Route definitions

  • Route::get('/docs', [AdminDashboardController::class, 'docsIndex'])
  • Route::get('/docs/{page}', [AdminDashboardController::class, 'documentationPage'])

Key implementation files

  • app/Http/Controllers/Admin/DashboardController.php
  • config/docs.php
  • resources/views/admin/docs/index.blade.php
  • resources/views/admin/docs/page.blade.php

The controller checks whether docs are enabled and resolves metadata for each documentation page before rendering the Blade templates.

4. How to Use

  1. Open a documentation page from the catalog above.
  2. Follow the tutorial sections for access, purpose, workflow, UI parts, routes, and related pages.
  3. Use the same documentation structure when adding a new admin module.
  4. Keep one documentation page per route or admin module for easier handover.

5. Enable / Disable

Docs visibility is controlled by the ADMIN_DOCS_ENABLED setting in the environment file.

ADMIN_DOCS_ENABLED=true

Shows docs links and pages.

ADMIN_DOCS_ENABLED=false

Hides docs links and returns 404 for docs routes.

After changing the toggle, run php artisan optimize:clear.

6. Add New Pages

  1. Open config/docs.php and add a new slug to the pages array.
  2. Set the page type and define route patterns, workflow, UI sections, and related docs.
  3. Ensure the corresponding view files exist and are referenced correctly.
  4. Reload the docs center and verify the new card appears.
